# 0003 设置与主题

- 状态：已采纳
- 日期：2026-10-02
- 来源：DevHub ADR 0007

## 背景

关闭窗口行为、主题等需要用户可调。不同设置的作用范围不同：有的决定主进程行为，有的只影响当前设备的显示。

## 决策

### 两类设置，两处存储

| 类别     | 内容                                    | 存储                                                                                      | 原因                        |
| -------- | --------------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------- |
| 核心设置 | 关闭窗口行为 `closeAction`（tray/quit） | core 的 `userData/settings.json`（zod 校验），API `getSettings` / `updateSettings(patch)` | 决定主进程行为，core 需读取 |
| 显示偏好 | 主题（跟随系统 / 浅色 / 深色）          | renderer 的 localStorage，键由 appId 派生（`<appId>.theme`）                              | 只影响当前设备的显示        |

- 修改立即生效，没有「保存」按钮：core 发出 `settings-updated` 事件，主进程据此更新关闭窗口行为。
- 部分更新使用单独的 patch schema（字段可选、不带默认值），避免 `.partial()` 下默认值覆盖未修改的字段。
- 新增设置项时按上表判断归属；新增的核心设置在 `packages/shared/src/settings.ts` 声明并带默认值，旧文件缺少字段时可直接读取。

## 备选与理由

- 全部放进 settings.json：显示偏好与设备相关，不应随核心数据同步。
- 全部放 localStorage：core 读不到。
- 设置用弹窗：页面更容易浏览与扩展。
