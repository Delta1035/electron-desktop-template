# 0002 本地持久化：JSON 文件

- 状态：已采纳
- 日期：2026-10-02
- 来源：DevHub ADR 0002

## 背景

应用需要持久化少量数据（示例中的便签、设置）。单用户、单进程（有单实例锁），数据量小。

## 决策

使用 zod 校验的 JSON 文件，存放在 Electron `userData` 目录。目录以 `app.config.json` 的 appId 命名，开发模式追加 `-dev`，避免与已安装版本共用数据和单实例锁；显式传入的 `--user-data-dir` 优先。

- 通用模块 `core/storage/json-store.ts`：读取时校验；文件缺失返回默认值；文件损坏则备份为 `<file>.corrupt-<时间戳>` 并以默认值启动；写入采用「临时文件 + rename」保证原子性。
- 各服务通过 `core/storage/serial-state.ts` 内存缓存数据，并串行化「读-改-写」，避免并发更新丢失；提交成功后再发布事件。
- 退出时等待写入队列清理完成。

## 备选与理由

- SQLite（better-sqlite3）：查询能力强，但需要原生模块编译、增加打包复杂度；小数据量用不上。派生应用确有查询需求时再评估并新增 ADR。
- JSON 可以直接打开查看和手工修改，便于调试。
